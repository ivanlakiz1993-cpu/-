# Коллекция новостей для собственной CMS

В редакторе ровно четыре поля:

| Поле | JSON | Формат |
| --- | --- | --- |
| Дата | `date` | `YYYY-MM-DD` |
| Заголовок | `title` | Строка |
| Текст | `text` | Обычный текст; пустая строка между абзацами |
| Фотография | `photo` | Путь к изображению на домене сайта, например `/uploads/news/photo.jpg` |

`slug` — служебный уникальный идентификатор записи для адреса. Его генерирует CMS; латинские буквы в нижнем регистре, цифры и дефисы. Это не дополнительное поле редактора.

Общий шаблон: `news-article.html?slug=victory-day`. Список `news.html` и шаблон используют один источник `news-source.js`.

Пока API не реализовано, источник — `content/news.json`. Текст поздравления взят из Figma; у остальных трёх существующих новостей сохранены заголовки, даты и фотографии, полный текст не придуман.

## Подключение API

В `news-cms-config.js` заменить `null` на `'/api/news'`. Включить API только после его реализации: при ошибке API локальная коллекция не подставляется вместо отсутствующей записи.

- `GET /api/news` возвращает `{ "items": [ ... ] }`, только доступные посетителям записи. Сайт сортирует их по дате от новых к старым.
- `GET /api/news/:slug` возвращает одну запись; для отсутствующей или недоступной записи — HTTP 404.
- Одна запись:

```json
{
  "slug": "victory-day",
  "date": "2025-05-09",
  "title": "Поздравляем с Днем победы!",
  "text": "Первый абзац.\n\nВторой абзац.",
  "photo": "/uploads/news/victory.jpg"
}
```

Публичный API и фотографии обслуживаются на домене сайта: текущая CSP разрешает запросы и изображения с этого домена. Админка, загрузка файлов, хранение, авторизация и публикация реализуются отдельно на сервере; ключи доступа в браузерный код не добавляются.

Текст выводится через `textContent`, HTML из редактора не выполняется. Страница показывает состояния отсутствующей записи и ошибки загрузки. Если коллекция временно недоступна, список сохраняет исходные карточки. Старые категории существующих карточек сохранены на стороне интерфейса; в редактор новые поля для них не добавлены.
